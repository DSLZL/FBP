# Factorio Blueprint Printer (蓝图自动打印机)

**Factorio Blueprint Printer** 是一个为《异星工厂》(Factorio) 设计的自动化建造辅助模组。它能够自动检测玩家周围的虚影（Ghosts）、升级规划和拆除规划，并利用玩家背包中的物品自动完成建造、升级或拆除工作。

这就像是一个随身的个人机器人指令平台，但它消耗的是你的背包物品，并不需要建设机器人或机器人指令模块（当然，它也支持与机器人协同工作）。

## ✨ 主要功能

本模组包含以下核心功能，您可以在游戏内的配置界面中独立开关每一项：

*   **自动放置 (Auto Place)**: 自动检测周围的实体虚影，并使用背包中的对应物品进行建造。支持保持物品的健康值和质量（Quality）。
*   **自动升级 (Auto Upgrade)**: 自动检测被升级规划器标记的实体，并尝试使用背包中的高级物品进行替换。旧物品会自动返还到背包。
*   **自动拆除 (Auto Deconstruct)**: 自动移除被红色拆除规划器标记的玩家建筑（如传送带、组装机等）。
*   **自动开采 (Auto Mine)**: 自动开采被标记为拆除的 **树木** 和 **岩石**。
    *   *特色功能*: 这是一个独立的选项。为了防止误操作，如果同时开启了自动拆除和自动开采，模组会**优先**拆除玩家建筑，然后再去处理树木和石头。
*   **自动插入模块 (Auto Modules)**: 自动向实体（如组装机、电炉）中插入虚影请求的插件模块。
*   **自动填海 (Auto Landfill)**: 如果蓝图中有填海虚影，且背包中有填海料，自动填海。

## ⚙️ 使用方法

### 开启/关闭
*   **快捷键**: 点击快捷栏中的 **"蓝图打印机开关"** 按钮（或自定义快捷键）来一键激活/停用所有功能。
*   **配置界面**: 使用快捷键或点击模组GUI按钮打开 **配置菜单**，在这里你可以勾选想要启用的具体功能（例如，你可以只开启“自动拆除”而不开启“自动建造”）。

### 设置选项 (ESC -> 选项 -> 模组设置)
*   **打印速度 (Tick间隔)**: 调整扫描和建造的频率。数值越小速度越快，但可能会增加UPS负载（默认 30 ticks）。
*   **扫描半径 (Scan Radius)**: 限制打印机的工作范围（默认 100 格）。在编辑器模式或拥有超大建造范围时，限制此数值可防止游戏卡顿。
*   **批量放置模式**: 开启后，模组会尝试一次性处理多个请求，效率更高。
*   **为我启用蓝图打印机**: 每个玩家独立的全局开关。如果您暂时不想使用本模组，可以在这里彻底关闭。

## 🔒 多人游戏与权限

本模组对多人游戏有着完善的支持：

1.  **管理员 (Admin)**: 始终拥有使用权限（除非自己在设置中关闭）。
2.  **普通玩家**:
    *   默认情况下，普通玩家可能无法使用（显示 "仅限管理员！"）。
    *   **启用方法**: 管理员需要在 **地图设置 (Map Settings)** -> **模组设置** -> **全局** 中，勾选 **"允许他人使用 (Allow Others)"**。
    *   开启该选项后，服务器内的所有玩家均可使用本模组。

## 🛠️ 常见问题

**Q: 为什么提示 "无物品栏！" (NO INVENTORY!)?**
A: 模组需要访问玩家的主背包来进行物品交换。如果您处于上帝模式或者某些特殊的控制器状态下，可能无法检测到背包。请切换回正常角色或确保控制器带有背包。

**Q: 为什么提示 "蓝图打印机已在您的用户设置中禁用"?**
A: 请检查 **选项 -> 模组设置 -> 个人**，确保 **"为我启用蓝图打印机"** 处于勾选状态。

**Q: 为什么提示 "仅限管理员！" (Admin only!)?**
A: 您当前不是管理员，且服务器未开启 "允许他人使用" 的全局选项。请联系服务器管理员开启。

**Q: 遇到未知错误怎么办？**
A: 在控制台输入命令 `/fbp-check`，它会打印出详细的诊断信息（包括您的权限状态、背包状态等），请将这些信息反馈给作者。
